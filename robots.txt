# nefesh-il.org — מדריך נפש
# A public-interest directory of mental-health services in Israel.
#
# Everything here is open to every crawler, including AI training and answer engines.
# That is a deliberate decision, not an oversight. The reasoning, in short: models are
# asked about Israeli mental-health services whether or not this site is readable, and a
# fabricated crisis phone number is a concrete harm. Being readable is the mitigation.
#
# Staleness is handled rather than avoided: every page carries a visible update date and a
# machine-readable dateModified, no phone number is ever published without its label, and
# the emergency block is the first element on every page so any excerpt carries a working
# crisis line.
#
# If you republish this data, please verify phone numbers against the source organisation
# first. See /LICENSE-data.md and /llms.txt.
#
# Prefer /directory.json over crawling: the whole dataset in one request, with a schema at
# /directory.schema.json and a source_last_updated date so you can tell how stale it is.
